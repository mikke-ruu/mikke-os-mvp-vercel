# MarketNote Implementation Spec 08: Finance Categories

MarketNoteの収支カテゴリ管理ページ仕様です。収支ページで使う売上カテゴリ / 経費カテゴリを、設定画面から管理できるようにします。

## 目的

- 収支ページのカテゴリ候補をユーザーが自分用に調整できるようにする。
- 売上カテゴリと経費カテゴリを分けて管理する。
- よく使うカテゴリを分かりやすく表示する。
- 将来的にDESK収支、Order、Fund、Session、Academyにも展開できるカテゴリ管理の土台にする。

## ルート

```text
/settings/finance-categories
```

設定トップの `収支カテゴリ` 行から遷移する。

## データ構造

MVPではDB変更せず、フロント側の保存から始める。

想定構造:

```text
id
type: revenue / expense
name
is_default
is_active
is_favorite
sort_order
```

将来的にはユーザー単位の設定としてDB保存する。

候補テーブル案:

```text
market_finance_categories
- id
- user_id
- category_type
- name
- is_default
- is_active
- is_favorite
- sort_order
- created_at
- updated_at
```

## MVP操作

- 売上カテゴリ / 経費カテゴリの切り替え
- カテゴリ一覧表示
- カテゴリ追加
- カテゴリ名編集
- カテゴリ削除、または非表示
- よく使うカテゴリ表示
- 非表示カテゴリの復帰
- 保存
- 保存後、収支ページのカテゴリ候補に反映する

## UI方針

Mikke OS Design SystemとMarketNote D案に合わせる。

- 白ベース
- 細線
- 軽いカード
- 弱い影
- オレンジアクセント
- グリーン補助
- ニュートラルグレー
- 入力欄は軽く
- 押せるものは押せる見た目にする
- 押せないものは押せそうに見せない
- 未実装アイコンは出さない

チェックテンプレート管理と近い操作感にする。


## 収支ページとの接続

収支ページの売上内訳 / 経費内訳で使うカテゴリ候補は、この設定を参照する。

MVPでは以下でよい。

- 設定ページで保存
- 収支ページを開いた時に保存済みカテゴリを読み込む
- 非表示カテゴリは候補に出さない
- よく使うカテゴリは候補内で先頭に寄せる、または設定画面で分かるようにする

## 支払い方法管理への共通化メモ

支払い方法管理も、以下の構造を流用できる。

```text
id
name
is_default
is_active
is_favorite
sort_order
```

そのため、MVPでは完全な共通コンポーネント化を急がず、同じ操作感と保存方針を揃える。
