# MarketNote Implementation Spec 08: Finance Categories

MarketNoteの収支カテゴリ管理ページ仕様です。

## 目的

収支ページで使う売上カテゴリ / 経費カテゴリを、設定画面から管理できるようにする。

- 収支ページのカテゴリ候補をユーザーが自分用に調整できるようにする
- 売上カテゴリと経費カテゴリを分けて管理する
- よく使うカテゴリを分かりやすく表示する
- 将来的にDESK収支、Order、Fund、Session、Academyにも展開できるカテゴリ管理の土台にする

## ルート

```text
/settings/finance-categories
```

設定トップの `収支カテゴリ` 行から遷移する。

## MVP操作

- 売上カテゴリ / 経費カテゴリの切り替え
- カテゴリ一覧表示
- カテゴリ追加
- カテゴリ名編集
- カテゴリ非表示
- 非表示カテゴリの復帰
- よく使うカテゴリの設定
- 上へ / 下への矢印移動による並び替え
- 保存
- 保存後、収支ページのカテゴリ候補に反映する

## 削除と非表示の方針

MVPではカテゴリの完全削除は行わない。

理由:

- 過去の収支データとの整合性を守るため
- すでに使われたカテゴリを消すと、過去データの分類が分かりにくくなるため

使わなくなったカテゴリは `非表示` として扱う。

将来的には以下を検討する。

- 未使用カテゴリのみ削除可能にする
- 使用済みカテゴリは非表示のみ許可する
- 削除前に、該当カテゴリを使った収支レコード数を表示する

## カテゴリ名変更時の注意

現在のMVP実装では、収支レコード側にもカテゴリ文字列を保存しているため、既存レコードの文字列が自動で一括変更されるわけではない。

ただし将来的にカテゴリID連携やカテゴリ別集計を強化する場合、カテゴリ名変更が過去データの見え方に影響する可能性がある。

そのためMVPでも、カテゴリ名変更時には以下の警告を表示する。

```text
このカテゴリはすでに収支データで使用されています。

カテゴリ名を変更すると、過去にこのカテゴリで登録した収支データの表示名も変更されます。

意味が変わる場合は、名前を変更せず、新しいカテゴリを追加してください。

変更してもよろしいですか？
```

ボタン:

- キャンセル
- 変更する

使用済み判定ができるようになったら、使用済みカテゴリのみ警告する。
MVPでは、カテゴリ名変更時に編集セッション内の初回変更で警告する。

## 並び替え

カテゴリは売上カテゴリ / 経費カテゴリそれぞれで並び替えできる。

- ドラッグではなく、上へ / 下への矢印移動で行う
- 一番上のカテゴリは上へ移動できない
- 一番下のカテゴリは下へ移動できない
- 保存後、収支ページのカテゴリ候補にも同じ順番で反映する
- よく使うカテゴリは表示上の目印であり、並び順を自動で変えない
- 操作アイコンが増えすぎないよう、D案の軽いUIに合わせる

## UI方針

Mikke OS Design SystemとMarketNote D案に合わせる。

- 白ベース
- 細線
- 軽いカード
- 弱い影
- オレンジアクセント
- グリーン補助
- ニュートラルグレー
- 入力欄は軽く
- 押せるものは押せる見た目にする
- 押せないものは押せそうに見せない
- 未実装アイコンは出さない

チェックテンプレート管理と近い操作感にする。

## 収支ページとの接続

収支ページの売上内訳 / 経費内訳で使うカテゴリ候補は、この設定を参照する。

MVPでは以下でよい。

- 設定ページで保存
- 収支ページを開いた時に保存済みカテゴリを読み込む
- 非表示カテゴリは候補に出さない
- 並び順は `sort_order` を使う
- よく使うフラグでは候補順を自動変更しない
