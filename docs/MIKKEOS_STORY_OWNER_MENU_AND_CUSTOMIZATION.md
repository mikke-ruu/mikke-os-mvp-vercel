# mikkeOS Story Owner Menu and Customization

作成日: 2026-07-09

このdocsは、Storyを見た人に見せる名刺部分と、ログイン中の本人が使う管理導線を分けるためのメモです。

## 1. 基本方針

Storyは外部に見せる名刺型ミニホームページです。

ただし、ログイン中の本人には、Story右上のメニューから以下へ移動できるようにします。

- 持っているmikkeOSアプリ。
- Story管理画面。
- 表示ON/OFF設定。
- デザイン設定。
- まだ繋げていないアプリの提案。

公開ユーザーに見せる内容と、本人用の管理導線は分けて扱います。

## 2. アプリ間の移動

Storyから以下のように移動できる状態を目指します。

```text
Storyを見る
↓
MarketNoteで出店や活動を管理する
↓
Item Studioで作品を整理する
↓
DESKで売上・経費を確認する
↓
Storyに戻って外に見せる内容を整える
```

他のアプリからも同じように、持っているアプリへ移動できる共通導線を持たせる方針です。

## 3. 持っているアプリだけ表示

本人用メニューには、ユーザーが持っているアプリだけを表示します。

初期表示例:

```text
MarketNote
Item Studio
Order
Session
Academy
```

持っていないアプリは通常メニューには混ぜず、必要なタイミングで「繋げますか」と提案します。

提案例:

```text
Communityを繋げますか
Eventを繋げますか
Academyを繋げますか
```

将来的には、ユーザーごとに便利な機能が揃った「自分だけのmikkeOS」になることを目指します。

## 4. Story管理で扱う設定

Story管理では、以下を編集できるようにする方針です。

```text
表示ON/OFF
背景色
背景画像
アクセントカラー
文字サイズ
テンプレート
作品の表示順
口コミの表示順
リンクの表示順
活動サマリーの表示ラベル
```

テンプレートは将来的に以下のように分けられる可能性があります。

```text
無料テンプレート
有料テンプレート
ビジネス向け
クリエイター向け
講師向け
イベント主催者向け
ショップ向け
```

## 5. 今回の実装範囲

今回の実装では、`/story` の右上に本人用メニューを追加しました。

入れたもの:

- 持っているアプリへの入口。
- Story管理への入口。
- 表示ON/OFF、デザイン設定、文字サイズ、テンプレートの管理項目。
- まだ繋げていないアプリの「繋げますか」提案。

まだ保存処理や本接続は入れていません。
