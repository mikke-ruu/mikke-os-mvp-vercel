# 見積もり表示証跡

CLI生成 `20260908101940_academy_first_publication_quote_display.sql`。取消ingressとは独立した差分。Supabase未適用、catalogは無seed。

法務実装ノートの要求に合わせ、quoteへplan_key/plan_name/discount_description/consent_revisionを固定保存する。値はprivateの版付きquote_display_catalogから取得する。未設定ならquote発行・申込みはquote_display_metadata_requiredで拒否する。クライアントや別APIの値で補完しない。

catalogキーはpolicy_version/pricing_revision/plan_key。既存の人数帯でplan_keyを決定し、料金計算は変更しない。plan_nameとdiscount_descriptionはレビュー済みの正式表示をactivation時に登録する。fixtureの名称は本番へ使わない。catalog行の更新・削除、quote発行後の表示差替えは禁止。改版は新しいpricing_revisionで行う。

通常quote RPCはsnake_caseで追加項目を返す。setup_completeの原quoteはplanKey/planName/discountDescription/consentRevisionを返す。setup確認とprepare/publishでpolicyの現在同意版を再検査する。prepare保存にも同一quoteの表示証跡を複写し、同じquoteの同意表示を後から書き換えない。

PGlite最小fixtureで、catalog欠落拒否、server表示の返却、quote表示差替え拒否、setup_complete原quoteとの一致を検査する。全DB schema、実Auth、Stripe、商用表示値は別ゲート。
