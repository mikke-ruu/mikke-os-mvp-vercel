# mikkeOS Story Profile Direction

作成日: 2026-07-09

このdocsは、mikkeOSのStoryを「公開Activity Log一覧」ではなく、「名刺・自己紹介・ミニホームページ・活動ポートフォリオ」として扱うための方針メモです。

## 1. Storyの役割

Storyは、本人や事業者が外部に見せるための公開プロフィールです。

主な役割:

- 名刺代わりになる自己紹介ページ。
- 活動実績をまとめたミニホームページ。
- 作品、講座、イベント、依頼窓口、外部リンクをまとめる入口。
- お客様レビューや公開してよい実績を見せる場所。
- Order / Session / Event / Academy / Community など、mikkeOS内の公開フロントへつなぐ場所。

Storyは、細かな行動ログを時系列で人に見せる場所ではありません。

## 2. Storyに出すもの

Storyに出す中心は、本人が選んだ公開用の情報です。

例:

```text
プロフィール
ブランド紹介
活動ジャンル
対応エリア
外部リンク
ショップリンク
SNSリンク
公開中の講座リンク
公開中のイベントページリンク
Order / Session / Event / Academy / Community の公開フロントへのリンク
選択した作品ポートフォリオ
お客様レビュー
出店回数
販売数
依頼件数
講座開催数
認定数
イベント開催数
コミュニティ運営実績
```

Activity Logは、これらの数字や実績を作るための元データとして使います。

## 3. Storyに出さないもの

Storyに、細かな行動情報を自動表示しません。

初期では出さないもの:

```text
次にどこへ出店するか
何月何日に誰と会うか
どのイベントに参加予定か
誰から受注したか
誰が申し込んだか
誰が講座に参加したか
どの生徒と授業したか
どの会員が参加したか
売上金額
支払い情報
請求情報
内部メモ
学習進捗
課題内容
評価内容
```

予定や細かな行動ログは、本人のスケジュールや行動パターンを推測できるため、Storyへ自動表示しません。

## 4. Activity Logとの関係

Activity Logは、mikkeOSの共通台帳です。

ただし、Activity Logの1件1件をそのままStoryに並べるわけではありません。

```text
Activity Log = 全記録の台帳
Story素材候補 = 公開プロフィールの材料になり得る記録
Story Profile = 本人が選んだ公開プロフィール
```

例:

```text
Activity Log:
出店した / 販売した / 受注した / 講座を開催した / レビューをもらった

Story Profile:
出店 30回 / 販売 50件 / 制作依頼 20件 / 講座開催 8回 / レビュー 12件
```

## 5. MarketNoteの扱い

MarketNoteの出店予定やスケジュールは、Storyに自動表示しません。

理由:

- 出店予定は、本人の行動予定を外部に見せることになる。
- MarketNoteを出店以外の予定管理に使う人が出る可能性がある。
- 出店以外の用途で使った予定がStoryに出ると、意図しないスケジュール共有になる。

初期方針:

```text
出店予定: Story非表示
出店実績: 集計値としてStory素材候補
個別の出店情報: 本人が明示的に公開したものだけ表示候補
出店以外の用途: Story側で表示オフ、または汎用の活動回数として扱う
```

## 6. Item Studioの扱い

Item Studioの商品登録は、Storyタイムラインへ自動表示するものではありません。

本来の使い方:

- 商品を登録する。
- 写真や説明を整える。
- Story側で見せたい作品だけ選ぶ。
- 選択した作品をポートフォリオとして表示する。

初期方針:

```text
作品登録ログ: Story素材候補
販売記録: DESK対象、Story非対象
ポートフォリオ表示: 本人が選んだ作品だけ
```

## 7. Academy / Communityの扱い

AcademyやCommunityも、細かな内部行動はStoryへ自動表示しません。

AcademyでStory素材候補になるもの:

```text
公開中の講座
講座開催数
認定数
講師数
公開レビュー
公開可能な講師ページ
```

CommunityでStory素材候補になるもの:

```text
公開中のコミュニティ
イベント開催数
勉強会開催数
ライブ開催数
公開可能なコミュニティ紹介
```

Storyに出さないもの:

```text
受講者情報
会員情報
課題内容
学習進捗
コメント内容
内部投稿
支払い情報
```

## 8. 既存docsの読み替え

既存docsで使っている `Story対象` という言葉は、今後は原則として `Story素材候補` と読み替えます。

`Story対象` は、自動公開するログという意味ではありません。

今後の意味:

```text
Story素材候補 = 本人が選べば、Story Profileの数字・作品・レビュー・リンクなどに使える可能性がある
```

## 9. 今後の実装方針

Story画面は、将来的に以下の構成へ寄せます。

```text
プロフィール
活動サマリー
作品ポートフォリオ
レビュー
公開アプリリンク
外部リンク
公開中の講座 / イベント / 依頼窓口
```

Activity Logの公開タイムラインは、必要なら別枠または管理者向け確認表示として扱います。

Storyの中心は、本人が編集・選択できる公開プロフィールです。
