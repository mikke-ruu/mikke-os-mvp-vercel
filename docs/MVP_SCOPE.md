## Mikke OS App Names

- MarketNote: 出店・マルシェ活動管理
- Item Studio: 作品・商品・在庫・出品管理
- Order: 受注・納品・LPビルド式販売
- Fund: 応援購入・予約販売・支援ページ
- Session: 予約・相談・レッスン・時間販売
- Academy: 認定講座・講師・教材・仕入れ・コミュニティ運営
- Event: 主催者側イベント管理
- Story: 活動実績・プロフィール・ポートフォリオ表示
- DESK: 売上・経費・利益・顧客管理
- Activity Log: すべての活動記録の共通台帳
